# Original design decisions

The visual metaphor is an editorial research desk: warm off-white paper, near-black ink, fine rules, and a restrained orange-red highlight. A broad bounty ledger sits beside a compact deadline agenda. System sans-serif typography supports scanning while tabular numerals keep prizes, fees and dates aligned. Generous titles contrast with dense, readable metadata.

Desktop uses a split workbench; mobile stacks the agenda beneath the board and makes filters wrap without horizontal overflow. Detail pages emphasize reward and deadline first, then description, rules and entrant navigation. The leaderboard shows API metric labels and compact remaining rows rather than implying that returned rows equal total entries. Profiles connect public entrants back to their work.

Navigation, shortlist and comparison are explicit buttons and links. Visible focus rings, semantic landmarks, live status feedback and reduced-motion support are foundational. Dark mode uses charcoal paper and warm text while preserving the accent and information hierarchy. All visual assets are local except official README badges; the app avoids remote images.
